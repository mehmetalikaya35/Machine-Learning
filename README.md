# Machine-Learning

Bu depo, hazırladığım veri bilimi ve makine öğrenmesi projelerini içermektedir. 
Temel regresyon tekniklerinden başlayarak (Linear, Multiple, Polynomial), model düzenleme (Ridge, Lasso, ElasticNet) ve veri ön işleme (Scaling, Train-Test Split) gibi kritik konularda uygulamalı çalışmalar yer almaktadır. 
Cezayir orman yangınlarından öğrenci performans analizine kadar gerçek dünya veri setleri üzerinde modeller geliştirilmiştir.
